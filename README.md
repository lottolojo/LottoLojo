# Lotto LoJo

Moderne, luxe Lotto webapp voor besloten vriendengroep. Responsive, groen/geel kleurthema, premium uitstraling. Frontend: React, Tailwind, Framer Motion. Backend: Node.js, Prisma, PostgreSQL. Deployable op Render.com.

## Structuur
- apps/frontend: React-app
- apps/backend: Node.js API
- packages: gedeelde code (bijv. types)

## Deploy
- Zie instructies in apps/frontend en apps/backend
